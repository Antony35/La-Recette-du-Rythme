questions:
  - question: "Pendant la lecture, un nom de votre motif s'encadre à chaque cycle, mais vous n'entendez rien à ce moment-là. Qu'est-ce que ça vous apprend ?"
    options:
      [
        "Que ce nom n'existe pas dans le kit — le plus souvent, il est mal orthographié",
        "Que le son est joué trop doucement pour être entendu",
        "Que le motif contient une erreur de syntaxe",
        "Que le son est joué en dehors du cycle",
      ]
    answer: 0
    explanation: >-
      L'encadrement montre ce que le code demande, pas ce qui sonne : un nom
      inconnu s'encadre comme les autres, sans produire de son ni de message.
      Une erreur de syntaxe, elle, affiche un message et empêche la lecture.
      Encadré mais muet : vérifiez l'orthographe.
  - question: "Deux noms s'encadrent exactement en même temps. Qu'est-ce que ça veut dire ?"
    options:
      [
        "Deux sons tombent au même instant — voulu pour un accent, gênant si c'est un accident",
        "Le motif contient une erreur de syntaxe",
        "L'éditeur a pris du retard sur le son",
        "Les deux pistes utilisent la même banque",
      ]
    answer: 0
    explanation: >-
      Superposer deux sons peut renforcer un accent : dans le bloc « Trois
      pistes à l'œil », la caisse claire tombe avec la deuxième grosse caisse.
      L'encadrement montre leur simultanéité ; c'est le résultat recherché qui
      permet de dire si leur placement convient.
  - question: "Les deux questions à se poser devant la grille d'un cycle sont…"
    options:
      [
        "Deux marques dans la même colonne ? Une colonne vide qui ne devrait pas l'être ?",
        "Le motif tient-il en quatre temps ? Le tempo est-il correct ?",
        "Tous les sons viennent-ils de la même banque ? Le volume est-il égal ?",
        "Y a-t-il autant de marques que de pistes ? Le cycle est-il complet ?",
      ]
    answer: 0
    explanation: >-
      Ces deux questions couvrent l'essentiel des rythmes bancals : une
      superposition involontaire, ou un trou là où on attendait un coup. Le reste
      est affaire de goût, pas de correction.
  - question: "Pourquoi le cours ne fait-il pas tourner `.punchcard()` dans ses propres blocs ?"
    options:
      [
        "Parce que cette vue est conçue pour l'éditeur plein écran de strudel.cc, où le dessin occupe le fond de la page",
        "Parce qu'elle ralentit trop la lecture",
        "Parce qu'elle n'existe que pour les mélodies, pas pour les rythmes",
        "Parce qu'elle demande une banque de sons particulière",
      ]
    answer: 0
    explanation: >-
      Le dessin se fait dans un canevas plein écran : dans un bloc intégré au fil
      du texte, il n'a pas la place de s'afficher. D'où la consigne de l'ouvrir
      sur strudel.cc — et, dans le cours, des grilles dessinées à côté du code.
